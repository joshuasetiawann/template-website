How to use a template

No tooling required — every template runs straight off your disk.

  1. 1

    Browse & preview

    Open any template from this gallery. Each one runs fully offline in any modern browser.

  2. 2

    Copy one folder

    Every template is self-contained: index.html, style.css, script.js and a README.md.

  3. 3

    Make it yours

    Palettes live in CSS custom properties at the top of each style.css — swap colors and copy in minutes.
