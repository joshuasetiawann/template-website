Our club

Coding that feels like play

PixelPals started when two software engineers wanted their own kids to learn coding the joyful way — by building games and robots, not filling in worksheets.

Every club is small and buzzing with creativity. Kids start by snapping together colourful code blocks and quickly graduate to writing real code — all while making games, animations, and robots that genuinely work.

We follow each child’s curiosity. A kid who loves games builds games; a future roboticist programs robots. Learning sticks because it’s theirs, and because seeing your own creation come alive is pure magic.

Our mentors are patient, encouraging, and a little bit nerdy in the best way. They celebrate every bug squashed and every level completed, building confidence as much as coding skill.

At the end of each term, kids show their creations at our Demo Day, beaming as family and friends play the games they built. That pride is what keeps them coming back.

“My daughter built a game her whole class now plays. She walks taller because of PixelPals.”

— Carlos Mendez, PixelPals parent

The PixelPals path

From first block to real code

Kids level up step by step, just like in a game. Here’s the adventure they go on.

  1. 1
    LVL 1

    Snap & Play

    Kids snap colourful code blocks together to make characters move, dance, and react. Coding feels like play from minute one.

  2. 2
    LVL 2

    Make a Game

    Adding scores, levels, and rules, kids build their first real, playable game to show their friends.

  3. 3
    LVL 3

    Think Like a Coder

    Loops, conditions, and variables — the big coding ideas, learned through fun challenges, not lectures.

  4. 4
    LVL 4

    Program a Robot

    Kids bring code into the real world, programming robots to move, sense, and solve puzzles.

  5. 5
    LVL 5

    First Real Code

    Stepping up from blocks to typing real Python code, building games and mini apps.

  6. 6
    LVL 6

    Build for the Web

    Kids create their own websites with real code and publish them for the world to see.

  7. 7
    LVL 7

    Make a Project

    A bigger personal project — a game, app, or site — that’s entirely the child’s own idea.

  8. 8
    LVL 8

    Demo Day!

    Kids proudly show their creations to family and friends, who get to play and cheer.
