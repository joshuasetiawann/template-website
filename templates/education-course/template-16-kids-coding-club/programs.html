Block Coding (Scratch)

Ages 7–9

The joyful first steps of coding, by snapping blocks together.

Program overview

Block Coding is where young coders begin. By snapping together colourful code blocks in Scratch, kids make characters move, animations play, and their very first games run — learning the big ideas of coding while it all feels like pure play.

What kids build

  1. 01

    First Animations

    Making characters move, talk, and dance with code blocks.

  2. 02

    Simple Games

    Adding scoring and rules to build a first playable game.

  3. 03

    Loops & Events

    Big coding ideas like repeating and reacting, the fun way.

  4. 04

    My Own Creation

    A personal project the child designs and shows on Demo Day.

Learning outcomes

  • Build animations and simple games
  • Understand sequences and loops
  • Use events to make things react
  • Solve problems step by step
  • Debug and fix their own code
  • Proudly present a project

Robot Lab

Ages 9–13

Bring code to life by programming real robots.

Program overview

In Robot Lab, kids program real robots to move, sense their surroundings, and complete fun challenges. It’s coding you can see and touch — building logic and problem-solving as kids race, navigate mazes, and make their robots do clever things.

What kids build

  1. 01

    Meet Your Robot

    Driving and controlling a robot with simple programs.

  2. 02

    Sensors & Reactions

    Using sensors so the robot responds to its world.

  3. 03

    Challenges & Mazes

    Programming the robot to solve obstacle courses.

  4. 04

    Robot Showcase

    A final challenge to show off on Demo Day.

Learning outcomes

  • Program robots to move and turn
  • Use sensors to detect and react
  • Break challenges into steps
  • Test and improve their programs
  • Work with a coding partner
  • Complete a robotics challenge

  • Teamwork spirit

Python Pioneers

Ages 11–14

Step up from blocks to typing real code in Python.

Program overview

Python Pioneers takes confident young coders into real text-based programming. Writing actual Python, kids build games and mini apps, learning the language professionals use — with mentors making every new concept a fun, achievable challenge.

What kids build

  1. 01

    Hello, Python

    Typing first real code and seeing it run.

  2. 02

    Loops & Logic

    Variables, loops, and conditions in real code.

  3. 03

    Build a Game

    Coding a text or simple graphical game in Python.

  4. 04

    Mini App Project

    A personal app or game to present on Demo Day.

Learning outcomes

  • Write and run real Python code
  • Use variables, loops, and conditions
  • Build a game from scratch in code
  • Find and fix code errors
  • Read and understand others’ code
  • Create and present a project
