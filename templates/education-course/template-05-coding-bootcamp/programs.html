Full-Stack Engineering

Flagship

16 weeks from fundamentals to a deployed full-stack application.

Program overview

Our flagship track takes complete beginners to job-ready full-stack engineers. You’ll write JavaScript daily, build with React and Node, design databases in SQL, and ship two portfolio-grade applications — finishing with a career sprint that gets you interview-ready.

Curriculum modules

  1. 01

    Phase 1 · Foundations

    JavaScript, Git, and the command line across the first four weeks.

  2. 02

    Phase 2 · Front End

    HTML, CSS, the DOM, and React to build polished interfaces.

  3. 03

    Phase 3 · Back End & Data

    Node, Express, REST, authentication, and Postgres.

  4. 04

    Phase 4 · Projects & Career

    Solo and team capstones plus a four-week career sprint.

Learning outcomes

  • Build and deploy full-stack web apps
  • Write idiomatic JavaScript and React
  • Design and query relational databases
  • Build and secure REST APIs
  • Collaborate with Git and code review
  • Pass a technical coding interview

Data & Analytics

In demand

14 weeks turning raw data into real decisions.

Program overview

The Data & Analytics track trains you to wrangle, analyse, and visualise data that drives decisions. You’ll master Python, pandas, and SQL, build dashboards, and complete an end-to-end analytics project on a real dataset before the career sprint.

Curriculum modules

  1. 01

    Phase 1 · Python & SQL

    Programming foundations and querying real databases.

  2. 02

    Phase 2 · Analysis

    pandas, statistics, and cleaning messy real-world data.

  3. 03

    Phase 3 · Visualisation

    Dashboards and storytelling that make data persuasive.

  4. 04

    Phase 4 · Capstone & Career

    An end-to-end analytics project plus the career sprint.

Learning outcomes

  • Write Python for data analysis
  • Query and join data in SQL
  • Clean and shape messy datasets
  • Build clear, persuasive dashboards
  • Communicate insights to stakeholders
  • Pass an analytics case interview

Cloud & DevOps

New

12 weeks shipping and operating real infrastructure.

Program overview

The Cloud & DevOps track is for those who want to build the systems software runs on. You’ll learn Linux, Docker, CI/CD pipelines, and AWS, automating deployments and operating production-style infrastructure end to end.

Curriculum modules

  1. 01

    Phase 1 · Linux & Scripting

    The command line, Bash, and networking fundamentals.

  2. 02

    Phase 2 · Containers

    Docker, images, and orchestrating multi-service apps.

  3. 03

    Phase 3 · CI/CD & Cloud

    Pipelines, infrastructure-as-code, and AWS core services.

  4. 04

    Phase 4 · Capstone & Career

    Deploy and operate a full system, then the career sprint.

Learning outcomes

  • Operate Linux systems confidently
  • Containerise apps with Docker
  • Build CI/CD deployment pipelines
  • Provision cloud infrastructure on AWS
  • Automate with infrastructure-as-code
  • Pass a DevOps technical interview
