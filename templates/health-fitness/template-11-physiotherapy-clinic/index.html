Where Does It Hurt?

Start with the sore spot

Choose the area giving you trouble and we'll show the usual path through assessment and rehab.

Most lower-back pain settles with staged loading. Path: 45-min assessment → hands-on care as needed → Back Care class block → 6-week retest.

Desk-heavy necks respond to graded mobility plus strength. Path: assessment → manual therapy → Shoulder Rehab class → workstation review.

From runner's knee to post-op ACL: testing first. Path: assessment + strength diagnostics → Knee Rehab class → return-to-sport testing.

Sprains heal; stiff, weak ankles linger. Path: assessment → balance & calf capacity work → Run & Gait Lab if you run.

Hips hide in backs and knees. Path: assessment with strength testing → targeted loading plan → gym-floor progressions.

Pain that has overstayed needs a different map. Path: extended assessment → Chronic Pain Program (8 weeks) → paced milestones.
