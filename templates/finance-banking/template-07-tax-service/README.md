# BrightReturn — Tax Service Template

Friendly, flat-fee tax filing with real experts who chase every credit and deduction.

## Features
- Four fully responsive, file://-safe pages built with pure HTML5, CSS3 and dependency-free vanilla JavaScript
- friendly-approachable (V5) visual design with a distinct palette, typography and component styling
- Live tax estimator (income and filing status &rarr; federal tax, marginal/effective rate and take-home) with instant updates as you type or drag
- Full plans listing with descriptions, indicative rates and feature checklists, plus a transparent rates table
- Count-up statistics, scroll-reveal animations (reduced-motion safe) and micro-interactions
- CSS-built app / card mockup, security badge bands and an FAQ accordion
- JavaScript-validated enquiry form with inline errors and an accessible status message
- Accessible by design: one `<h1>` per page, skip link, ARIA labelling, `:focus-visible` styles, 44px+ targets, back-to-top control
- Inline-SVG icons, gradients and patterns only — no external assets, fonts, scripts or network calls

## Pages
- `index.html` — homepage: hero, plans preview, the calculator, security/why-us, count-up stats, how-it-works, testimonials and a CTA.
- `services.html` — the primary page: full plans listing, the live calculator, a rates/pricing table, a trust & security band and an FAQ.
- `about.html` — company story, mission, the people behind brightreturn, a regulatory band and an impact stats section.
- `contact.html` — JavaScript-validated enquiry form, contact info cards, opening hours, a map placeholder, social links and an FAQ.

## How to Use
1. Open `index.html` in any modern browser — no build step, server or internet connection is required.
2. Use the top navigation to move between the four pages; every link resolves to a real, filled page.
3. Try the calculator on the homepage or at `services.html#calc` — results update live.

## Customization
- All colours, spacing and radii are defined as CSS custom properties in the `:root` block of `style.css` — change the accent there to retheme the whole site.
- Edit product names, rates and copy directly in the HTML; the calculator maths lives in the shared `script.js` and reads the input ids.
- Replace the brand name `BrightReturn`, the favicon letter and the contact details to make the template your own.
