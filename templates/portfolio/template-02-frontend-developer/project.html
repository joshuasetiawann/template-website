Overview

Overview

Ledgerline’s four web apps each carried their own button, modal and table implementations. I led the build of one accessible component kit to replace them all.

Forty-two components, tree-shakeable to a 28kb core, with visual-regression coverage and docs written for engineers in a hurry.

The brief

The challenge

The kit had to win adoption on merit — no mandate. That meant migration codemods, office hours, and components that were simply easier than copy-paste.

Method

The approach

  1. 01

    Profile

    Reproduce the problem with traces and a Lighthouse baseline. No fixes before flamegraphs — measurement is the spec.

  2. 02

    Architect

    Agree budgets and a component contract: bundle ceilings, a11y acceptance criteria, and what we are allowed to delete.

  3. 03

    Build

    Small PRs behind flags, visual-regression and axe tests on every commit, progressive enhancement as the default posture.

  4. 04

    Ship & verify

    Roll out to a slice of traffic, watch Web Vitals dashboards for a week, then delete the old path entirely.
