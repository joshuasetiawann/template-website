How I work

The approach

Different projects, same backbone. This is roughly how the work happens.

  1. 01

    Discover

    Stakeholder interviews, analytics review and five-second tests to find where the experience actually breaks — before a pixel moves.

  2. 02

    Define

    Journey maps and a sharply-worded problem statement, signed by product and engineering, so we are solving the same thing.

  3. 03

    Design

    Greyscale wireframes first, then high-fidelity flows built from design tokens and prototyped for real testing.

  4. 04

    Deliver

    Moderated usability rounds, accessibility checks and a handoff engineers can build without a meeting.
