How I work

The approach

Different projects, same backbone. This is roughly how the work happens.

  1. 01

    Define

    Pin down the decision behind the request. A vague metric is a vague answer; we sharpen the question first.

  2. 02

    Model

    Clean, joined, documented data with definitions everyone agrees on — the boring layer that makes the rest trustworthy.

  3. 03

    Analyse

    The right method for the question: cohorts, an experiment, a forecast — with uncertainty stated, not hidden.

  4. 04

    Communicate

    A chart that reads in one glance and a recommendation a non-analyst can act on by Monday.
