# Cedar Lodge Boarding — Pet Boarding Template

A multi-page pet boarding website template in the friendly-rounded style (V1).

## Features

- Four hand-built pages: home, services, about and contact — no build step, no dependencies
- A pet boarding services & booking page with full listings, prices and an interactive booking widget with live JavaScript validation
- Packages / plans section, FAQ accordion, count-up stat bands and scroll-reveal animations
- Accessible mobile navigation, back-to-top button, breadcrumb trails and `:focus-visible` outlines
- Inline-SVG data-URI favicon, CSS-gradient imagery and a unique friendly-rounded palette
- Pure HTML5, CSS3 and vanilla JavaScript — runs straight from `file://`
- Reduced-motion aware, ARIA-labelled and keyboard-friendly throughout

## Pages

- `index.html` — marketing home: hero, stats, services preview, about teaser, team, pricing teaser, gallery, testimonials and a booking widget.
- `services.html` — the primary page: breadcrumb, full service listing with prices, booking widget, packages (`#pricing`), FAQ accordion and a call to action.
- `about.html` — breadcrumb, story, mission, `#impact` count-up stats, full `#team` grid, facilities, accreditations and `#gallery`.
- `contact.html` — breadcrumb, JavaScript-validated form, info cards, opening hours, a CSS map placeholder, social links and FAQs.

## How to Use

1. Open `index.html` in any modern browser — no server required.
2. Edit the text directly in the HTML files to match your business.
3. Swap colours and fonts in the `:root` block at the top of `style.css`.
4. Update services, prices and team members in the relevant sections.

## Customization

- All colours live as CSS custom properties in `style.css` (`--c1`, `--c2`, `--c3`).
- The booking, contact and quote widgets are wired up in `script.js`; replace the success handlers with your own backend.
- Demo links are marked with `data-demo-link`; point them at your real pages.

This template is part of a 20-template PET-SERVICES library; each template uses a distinct brand, palette and content set.
